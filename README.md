# Fastapi-DB

Desarrollar una API RESTful usando FastAPI, implementando operaciones CRUD para diferentes entidades, y desplegarla en AWS utilizando una instancia EC2 para la aplicación y una instancia de Amazon RDS para la base de datos.

La solución deberá permitir la comunicación entre FastAPI → EC2 → RDS, de manera que la información gestionada por la API sea almacenada en una base de datos administrada en la nube.
